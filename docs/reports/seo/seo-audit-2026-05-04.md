### Problème critique : Canonical hérité du layout racine ❌

Le layout racine (`src/app/layout.tsx`) définit `alternates: { canonical: "/" }`. En Next.js App Router, si une page n'override pas `alternates`, elle **hérite le canonical du layout parent**. Les pages suivantes — toutes présentes dans le sitemap — auront un `<link rel="canonical" href="https://totemavise.com/" />` pointant vers l'accueil :

| Page affectée | Priorité sitemap | Fichier à corriger |
|---|---|---|
| `/livres` | 0.7 | `src/app/livres/layout.tsx` |
| `/notre-methode` | 0.5 | `src/app/notre-methode/page.tsx` |
| `/a-propos` | 0.4 | `src/app/a-propos/page.tsx` |
| `/nos-valeurs` | 0.4 | `src/app/nos-valeurs/page.tsx` |
| `/objectif` | 0.4 | `src/app/objectif/page.tsx` |

**Impact :** Google peut ignorer ces pages dans son index ou les fusionner avec l'accueil. Le correctif est simple : ajouter `alternates: { canonical: "/chemin" }` dans chaque `metadata`.

## Issues Trouvées

1. **Canonical erroné sur 5 pages du sitemap** (`/livres`, `/notre-methode`, `/a-propos`, `/nos-valeurs`, `/objectif`)  
   Ces pages héritent `canonical: "/"` du layout racine, signalant à Google que leur contenu canonique est l'accueil. Risque de désindexation ou de non-crawl.

### 🟡 Avertissements (impact modéré)

2. **OG image non standard (620×606)** sur toutes les pages statiques  
   Ratio portrait non optimal ; Facebook/Slack/Discord rognent les images OG au ratio 1.91:1 (1200×630).

3. **Description trop courte** sur `/series` (109 chars), `/jeux` (116 chars), `notre-methode` (~96 chars), `objectif` (~90 chars)  
   Google peut réécrire la méta-description si elle est trop courte.

6. **Accessibilité sitemap/robots depuis cet environnement** — À vérifier que Googlebot n'est pas affecté (Google Search Console → Inspection d'URL).

## Recommandations (par priorité)

### Priorité 1 — Corriger les canonicals manquants

Ajouter `alternates: { canonical: "/chemin" }` dans les pages/layouts concernés :

```ts
// src/app/livres/layout.tsx
export const metadata: Metadata = {
  title: "...",
  description: "...",
  alternates: { canonical: "/livres" },   // ← ajouter
  openGraph: { ... },                      // ← ajouter
}

// src/app/notre-methode/page.tsx
export const metadata = {
  title: "...",
  description: "...",
  alternates: { canonical: "/notre-methode" },  // ← ajouter
}
// Idem pour /a-propos, /nos-valeurs, /objectif
```

### Priorité 2 — Créer une OG image 1200×630

Créer `/public/og-default.png` (1200×630) avec le logo/branding Totem Avisé. Mettre à jour le layout racine et tous les layouts de catégorie :

```ts

  images: [{ url: "/og-default.png", width: 1200, height: 630, alt: "Totem Avisé" }],
},
```
