## 7. Recommendations

### Priority 1 — Image Optimization (C1)

```ts
// next.config.ts — remove or limit unoptimized flag
const nextConfig: NextConfig = {
  images: {
    // unoptimized: true,  ← REMOVE THIS
    remotePatterns: [ ... ],
  },
}
```

`unoptimized: true` was likely added to work around a Vercel build or TMDB image proxy issue. Instead, ensure all image hostnames are listed in `remotePatterns` (they already are). Re-enabling optimization will:
- Auto-convert to WebP/AVIF (smaller files, faster LCP)
- Generate `srcset` for responsive images
- Enable lazy loading by default

If you need to keep it for a specific domain, use a per-image `unoptimized` prop rather than the global flag.

### Priority 2 — /contact Page Metadata (C2)

Create `src/app/contact/layout.tsx`:

import type { Metadata } from "next"
