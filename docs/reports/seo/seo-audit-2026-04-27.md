## 7. Issues Found

### 🔴 Critical

**1. Image optimization disabled** — `next.config.ts` line 9  
`images: { unoptimized: true }` disables Next.js / Vercel image optimization globally. All images (posters, blog images, UI assets) are served at original resolution without WebP conversion or responsive `srcset`. This directly degrades LCP (Largest Contentful Paint), a confirmed Google ranking signal. Posters from TMDB at ~500×750 are served as-is.

**2. Blog post title double-suffix** — `src/app/blog/[slug]/page.tsx` line 85  
`title: \`${title} — Blog Totem Avisé\`` + layout template `"%s | Totem Avisé"` = "Post Title — Blog Totem Avisé | Totem Avisé". Fix: use just `title: post.seoTitle || post.title` (the "`— Blog Totem Avisé`" part is unnecessary as the template already identifies the site).

**3. `/collections` has no SEO metadata** — `src/app/collections/page.tsx`  
Full client component with no exported metadata. Priority 0.8 in sitemap with no unique title/description.

**4. `/recommandations` has no SEO metadata** — `src/app/recommandations/page.tsx`  
Same issue as `/collections`.

### ⚠️ High Priority

**5. OG image non-standard dimensions**  
All non-media pages use `/icon.png` (620×606, near-square). Social platforms (Facebook, Twitter/X, LinkedIn) crop or poorly render OG images that aren't 1200×630. Create a dedicated `og-image.png` at 1200×630 or use Next.js `ImageResponse` to generate it dynamically.

**6. Series meta description too short** — `src/app/series/page.tsx` line 57  
108 chars. Google recommends 120–160. Add ~12 chars of additional value.

### 🟡 Medium Priority

**7. Films `<title>` 2 chars over limit** — `src/app/films/page.tsx` line 56  
"Films — Avis et âges recommandés pour la famille | Totem Avisé" = 62 chars (rec. ≤60). Can be fixed by shortening to e.g. "Films — Avis et âges pour la famille".

**8. Séries `<title>` 6 chars over limit** — `src/app/series/page.tsx` line 56  
66 chars. Shorten to e.g. "Séries TV — Avis et âges pour la famille".

**9. Jeux description slightly short** — `src/app/jeux/page.tsx` line 57  
115 chars, 5 below the 120-char minimum. Easy to extend.

**10. Age range descriptions under 120 chars**  
Most age range descriptions in `src/app/age/[range]/layout.tsx` are 111–115 chars. All are slightly below minimum. None is critical but worth padding.

### ℹ️ Low Priority

**11. Homepage description at exact minimum boundary**  
120 chars — technically passing. An extra sentence about "guide pour parents" would add value for click-through rate.

**12. No `/jeux-video` → `/jeux` redirect**  
The route is `/jeux` but some older links or partner mentions might use `/jeux-video`. A Next.js redirect would be cheap insurance.
