## Résumé Exécutif

Le socle SEO technique est solide : robots.txt bien configuré, sitemap valide, JSON-LD complet, HTTPS, `lang="fr"`, metadata présente sur les pages principales. Deux problèmes nouveaux et actionnables ressortent de cet audit :

1. **6 pages ont un titre dupliqué** (`"Titre | Totem Avisé | Totem Avisé"`) à cause d'une collision entre le `title.template` du root layout et des chaînes statiques qui incluent déjà `"| Totem Avisé"`.
2. **10 pages du sitemap sont des composants `"use client"` sans `generateMetadata`** — elles reçoivent toutes le titre par défaut du layout, créant de la duplication de titre et des descriptions génériques indexées par Google.

### 2b. PROBLÈME CRITIQUE #1 — Titres dupliqués (6 pages)

Le root layout définit `title.template = "%s | Totem Avisé"`. Six pages exportent un `metadata.title` qui inclut déjà `"| Totem Avisé"`, causant un titre rendu de type **"Titre | Totem Avisé | Totem Avisé"** dans le HTML.

| Fichier | Titre actuel (metadata.title) | Titre rendu en HTML |
|---------|-------------------------------|---------------------|
| `src/app/bd/page.tsx` | `"Bandes Dessinées \| Totem Avisé"` | `"Bandes Dessinées \| Totem Avisé \| Totem Avisé"` |
| `src/app/objectif/page.tsx` | `"Notre mission \| Totem Avisé"` | `"Notre mission \| Totem Avisé \| Totem Avisé"` |
| `src/app/nos-valeurs/page.tsx` | `"Comment ça marche \| Totem Avisé"` | `"Comment ça marche \| Totem Avisé \| Totem Avisé"` |
| `src/app/a-propos/page.tsx` | `"À propos \| Totem Avisé"` | `"À propos \| Totem Avisé \| Totem Avisé"` |
| `src/app/notre-methode/page.tsx` | `"Notre méthode \| Totem Avisé"` | `"Notre méthode \| Totem Avisé \| Totem Avisé"` |
| `src/app/blog/[slug]/page.tsx` | `"${title} — Blog Totem Avisé"` | `"${title} — Blog Totem Avisé \| Totem Avisé"` |

**Fix :** Supprimer `| Totem Avisé` de la chaîne `metadata.title` — le template l'ajoute automatiquement.

```typescript
// ❌ Avant
export const metadata = { title: "Notre méthode | Totem Avisé" }

// ✅ Après
export const metadata = { title: "Notre méthode" }
// → Rendu : "Notre méthode | Totem Avisé"
```

Pour `blog/[slug]/page.tsx`, changer :
```typescript
// ❌ Avant
title: `${title} — Blog Totem Avisé`,

// ✅ Après
title: `${title} — Blog`,
// → Rendu : "Titre de l'article — Blog | Totem Avisé"
```

### 2c. PROBLÈME CRITIQUE #2 — 10 pages du sitemap sans metadata

Ces pages sont des composants `"use client"` qui ne peuvent pas exporter `generateMetadata`. Elles héritent toutes du titre par défaut du layout : **"Totem Avisé — Films, Séries TV et Jeux Vidéo en famille"**.

| Page | Priorité sitemap | Problème |
|------|-----------------|----------|
| `/age/2-4` | 0.8 | Titre et description identiques à la homepage |
| `/age/5-7` | 0.8 | Titre et description identiques à la homepage |
| `/age/8-10` | 0.8 | Titre et description identiques à la homepage |
| `/age/11-12` | 0.8 | Titre et description identiques à la homepage |
| `/age/13-15` | 0.8 | Titre et description identiques à la homepage |
| `/age/16-plus` | 0.8 | Titre et description identiques à la homepage |
| `/livres` | 0.7 | Pas de metadata, contenu mock uniquement |
| `/collections` | 0.8 | Pas de metadata |
| `/recommandations` | 0.8 | Pas de metadata |

Google voit 9 pages avec exactement le même titre/description → signal de duplication.

**Fix pour les pages `/age/[range]` :** Convertir en composant serveur avec `generateMetadata` :

```typescript
// src/app/age/[range]/page.tsx — Ajouter en haut (sans "use client")
export async function generateMetadata({ params }: { params: Promise<{ range: string }> }): Promise<Metadata> {
  const { range } = await params
  const ageRange = ageRanges[range]
  if (!ageRange) return {}
  return {
    title: `Contenus pour les ${ageRange.label}`,
    description: `Films, séries et jeux recommandés pour les ${ageRange.label}. ${ageRange.description}`,
    alternates: { canonical: `/age/${range}` },
  }
}
```

La page elle-même peut rester client via un composant enfant — seul le `generateMetadata` doit être dans le Server Component wrapper.

**Fix pour `/collections`, `/recommandations` :** Même pattern (wrapper serveur avec `generateMetadata` + composant client interne).

## Recommandations

### Priorité 1 — Titres dupliqués (30 min de fix)

Dans chaque page concernée, supprimer `| Totem Avisé` de la chaîne `metadata.title`. Le template du root layout l'ajoute automatiquement.

```
src/app/bd/page.tsx             "Bandes Dessinées | Totem Avisé"  →  "Bandes Dessinées"
src/app/objectif/page.tsx       "Notre mission | Totem Avisé"     →  "Notre mission"
src/app/nos-valeurs/page.tsx    "Comment ça marche | Totem Avisé" →  "Comment ça marche"
src/app/a-propos/page.tsx       "À propos | Totem Avisé"          →  "À propos"
src/app/notre-methode/page.tsx  "Notre méthode | Totem Avisé"     →  "Notre méthode"
src/app/blog/[slug]/page.tsx    "${title} — Blog Totem Avisé"     →  "${title} — Blog"
```

### Priorité 2 — Metadata sur les pages âge (2-3h)

Extraire la partie "use client" des pages `/age/[range]` dans un sous-composant. Le `page.tsx` parent redevient Server Component et peut exporter `generateMetadata`. Même chose pour `/collections` et `/recommandations`.

### Priorité 3 — Retirer `/livres` du sitemap ou brancher sur la DB

Tant que `/livres` affiche des mock data, soit retirer l'URL du sitemap, soit connecter la page à l'API DB (comme `/films` et `/series` le font).
