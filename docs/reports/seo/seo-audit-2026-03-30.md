## Recommendations

### Priority 1 — High Impact, Low Effort

**R1. Fix image optimization** (`next.config.ts`)
Remove `unoptimized: true` or switch to `unoptimized: false` (the default). Vercel provides built-in image optimization at no extra cost for reasonable traffic. This alone can significantly improve LCP scores.
```ts
// next.config.ts — remove or comment out:
// unoptimized: true,
```

**R2. Extend Series page description** (`src/app/series/page.tsx:27`)
Extend from 109 to 130–150 chars. Add something like: `... Avis détaillés, conseils de parents et recommandations pour accompagner vos enfants.`

**R3. Fix homepage `og:title`** (`src/app/layout.tsx:56`)
Replace the short "Totem Avisé" with the full page title:
```ts
openGraph: {
  title: "Totem Avisé — Films, Séries TV et Jeux Vidéo en famille",
  ...
}
```

### Priority 2 — Medium Impact, Low Effort

**R4. Add `WebSite` JSON-LD to homepage** (`src/app/layout.tsx`)
Add a `WebSite` schema with `SearchAction` to enable Google Sitelinks Search Box:
```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "Totem Avisé",
  "url": "https://totemavise.com",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://totemavise.com/recherche?q={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
```

**R5. Add `Article` JSON-LD to blog posts** (`src/app/blog/[slug]/page.tsx`)
Add `Article` structured data using the post's `title`, `publishedAt`, `author`, and `mainImage`. This unlocks article rich results in Google Search.

**R6. Add noindex to auth pages**
Add `export const metadata = { robots: { index: false } }` to `src/app/connexion/page.tsx` and `src/app/inscription/page.tsx`. These pages have no SEO value and consume crawl budget.

### Priority 3 — Low Impact

**R7. Fix Jeux page description** (extend to 130+ chars)

**R8. Fix `nos-valeurs` title** — change from "Comment ça marche" to something matching the slug, e.g., "Nos valeurs | Totem Avisé"

**R9. Create a 1200×630 default OG image**
Create a proper branded OG image (`/og-image.jpg`) at 1200×630 and use it for static pages (homepage, films, series, jeux). Currently `/icon.png` at 620×606 is used — acceptable but suboptimal for social sharing.

**R10. Verify Googlebot is not blocked by Vercel's WAF**
In Vercel dashboard → Security → Attack Challenge Mode, ensure Googlebot and other legitimate crawlers are whitelisted. The current setup returning 403 to all bots is concerning even if intentional for other bots.
