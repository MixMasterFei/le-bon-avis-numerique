## Problemes Critiques (a corriger immediatement)

### 1. Canonical manquant — Toutes les pages

Aucune page n'a de `<link rel="canonical">`. Google pourrait indexer des URLs dupliquees.

**Fix :** Ajouter dans `src/app/layout.tsx` :
```typescript
alternates: { canonical: "https://totemavise.com" }
```
Et dans `generateMetadata()` des pages dynamiques.

### 2. Pas de H1 sur homepage et pages listing

- Homepage : 5x H2, 0x H1
- `/films` : 0x H1

**Fix :** Ajouter un `<h1>` visible dans la hero section de chaque page.

### 3. Titre trop long — Homepage (75 car.) et /films meta desc (170 car.)

- Homepage titre : 75 caracteres (max 60)
- Homepage meta desc : 166 caracteres (max 160)
- `/films` meta desc : 170 caracteres (max 160)
- Media pages : titres souvent >60 car. a cause du pattern `— A partir de X+ ans ? Avis parents`

**Fix :**
- Homepage : `"Totem Avise — Films et series pour toute la famille"` (50 car.)
- Media pages : raccourcir le pattern `— Des X ans | Totem Avise` au lieu de `— A partir de X+ ans ? Avis parents | Totem Avise`

### 4. og:image manquant — Homepage + listing pages

Homepage et `/films` n'ont pas de `og:image`. Les media pages l'ont bien (poster TMDB).

**Fix :** Creer une image OG par defaut (1200x630) et l'ajouter dans le metadata du layout.

### 5. Invalid URL pages return `noindex`

Quand une URL `/media/<raw-uuid>` est accedee (sans le prefixe `movie:` / `tv:`), la page ne renvoie pas de 404 mais affiche le shell layout avec `meta robots: noindex`. Ce n'est pas grave pour le SEO (le sitemap a les bonnes URLs), mais idealement ces URLs devraient retourner un 404.

## Avertissements (a corriger sous 1 mois)

### 6. Images homepage en format legacy

Les 6 images de la homepage sont en JPG/PNG au lieu de WebP/AVIF. Elles sont servies directement depuis `/public/` sans passer par `next/image`.

**Fix :** Convertir en WebP ou utiliser le composant `SafeImage`/`next/image` qui convertit automatiquement.

### 7. 4 images sans dimensions width/height

Risque de CLS (Cumulative Layout Shift). Les images `hero-banner.jpeg`, `family-movie.jpg`, `parent-tablet.jpg`, `children-reading.jpg` n'ont pas de `width`/`height`.

### 8. 1 image sans alt sur homepage + 1 par media page

- Homepage : `/hero-banner.jpeg` — alt manquant
- Media pages : le poster dans la section hero a un `alt=""` vide (le second poster a le bon alt)

### 9. JSON-LD — `contentRating` manquant sur Movie, `numberOfSeasons` manquant sur TVSeries

- Movies : ajouter `contentRating` avec la classification CNC/CSA (ex: "Tous publics", "-12")
- TV : ajouter `numberOfSeasons`

### 10. robots.txt — Pas de regles pour les AI crawlers

Aucune directive pour GPTBot, ClaudeBot, CCBot, Google-Extended, etc. Si vous souhaitez bloquer le scraping AI :

```
User-Agent: GPTBot
Disallow: /

User-Agent: ClaudeBot
Disallow: /

User-Agent: CCBot
Disallow: /
```

### 11. Pas de favicon/icon dans le `<head>`

L'Organization JSON-LD reference `/icon.png` mais aucun `<link rel="icon">` dans le HTML visible (Next.js peut le gerer via le fichier convention).
